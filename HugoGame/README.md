Hugo & Amigos - jogo simples

Como usar:
- Abra `index.html` em um navegador moderno (Chrome/Edge/Firefox).
- Clique em Iniciar para começar o jogo e ouvir a historinha.
- Controles: Use as setas ou WASD para mover Hugo por toda a tela (top-down). Espaço toca um som.

Arquivos:
- `index.html` - página do jogo.
- `styles.css` - estilos simples.
- `script.js` - lógica do jogo e áudio sintetizado.

Objetivo:
- Colete criaturas amigas para ganhar pontos. Este é um exemplo simples para crianças; sinta-se à vontade para editar as imagens, sons e regras.

Imagens:
- Criei imagens SVG para Hugo (`hugo-pig.svg`), Capivara (`capivara.svg`), Pug (`pug.svg`) e Dragão (`dragon.svg`) — elas estão na mesma pasta do jogo e são usadas como sprites.
