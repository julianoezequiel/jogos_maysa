# Capivara Aventura — Maisa

Jogo simples em HTML/CSS/JS projetado para uma criança de 10 anos aprender e brincar.

Como abrir:
- Abra o arquivo `index.html` em um navegador moderno (Chrome, Edge, Firefox).

Arquivos principais:
- `index.html` — página principal do jogo.
- `styles.css` — estilos e layout.
- `script.js` — lógica do jogo, com comentários para aprendizado.
- `capivara-run.svg` — imagem da capivara com 4 frames de animação em uma só imagem.
- `bg-*.svg` — camadas do cenário para efeito parallax.

Como jogar:
- Use as teclas ↑ ↓ ← → ou W A S D para mover a capivara.
- Clique em Iniciar para começar. Evite obstáculos, cada obstáculo ultrapassado soma pontos.

Notas para estudo (para uma criança de 10 anos):
- Olhe `script.js` e procure comentários: eles explicam variáveis, laços, eventos e colisões.
- Experimente mudar a velocidade da capivara (procure `player.speed`) para ver o efeito.
